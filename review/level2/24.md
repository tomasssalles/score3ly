## Map

- **One Worker, three hosts.** `apps/worker/src/index.ts` (Hono app) runs (a) on Cloudflare, bindings `DB` (D1) and `PDFS` (R2) from `wrangler.deploy.jsonc`, secrets as Worker secrets; (b) under `wrangler dev` / `getPlatformProxy` (local dev, the tests via `testPlatform.ts`, `fill-call-places --local/--remote`) from `wrangler.local-dev.jsonc`; (c) on Node in `apps/desktop/src/server.ts`: `worker.fetch(request, env, ctx)` with `env = { ...SecretsFile.read(), DEV_PROVIDERS?, DB: NodeD1, PDFS: NodeR2 } as unknown as Env`. server.ts answers `/api/info` (`"desktop"`/`"local"`), `/api/secrets-file/open`, `/api/window/theme` and the web app's files itself, before the Worker (whose `/api/info` says `"cloudflare"`).
- **Contracts across hosts:** (1) the D1 surface the Worker uses (`prepare/bind/first/all/run/batch/exec`, `meta.changes`) ↔ `NodeD1`; (2) the R2 surface (`get/put{sha256,httpMetadata}/head/delete/list{prefix,cursor,limit}`, `object.size/uploaded/httpMetadata/body`) ↔ `NodeR2`; (3) secrets = every string value of `env` minus `NOT_SECRETS` (llmRoutes 653–666) ↔ `.dev.vars` (dotenv, Wrangler) / Worker secrets / `secrets.env` (`parseSecrets`); (4) `{ host }` of `/api/info` ↔ web `fetchHost`/`Host` (api.ts 92–95), `host.ts`; `WindowTheme` ↔ web `setWindowTheme`; (5) `request.signal` aborting on a closed client: Cloudflare by the compat flag, Node by @hono/node-server (it does).
- **Config and deployment:** `wrangler.jsonc.template` → `scripts/config.ts` (`writeLocalDevConfig`, `writeDeployConfig` from `cloudflare.env`; `parseAccount`/`formatAccount`/`withAccount`) → used by package.json scripts (`dev`, `deploy`, `migrate:local`, `test`), `setup-cloudflare.ts` (creates bucket + database, writes `cloudflare.env`), `fill-call-places.ts` (its own remote config), `scripts/appServers.ts` and `scripts/seedStats.ts` (local-dev). `.github/workflows/deploy.yml` writes `cloudflare.env` with `printf` and runs `npm run deploy`; `tests.yml` typechecks the workspaces, `npm test`, `npm run replay`.
- **Browser-driven scripts:** `appServers.ts` (servers on given ports, `api`, `sql`, `newProject`, `openProject`, `runToEnd`, `pipelineOf`) ← `replay.ts` (CI), `make-fixture.ts`, `screenshots.ts` (by hand). `seedStats.ts` writes SQL straight into a Wrangler local D1. `notices.ts` (+test) and `syntax.test.ts` stand alone.
- **eval:** a Vite viewer (`Viewer`, `PdfPane`, `useMarks`, `testsetServer` plugin) and a CLI (`engrave.ts`) over `testset/`; shares with the web app core's `drawPage`/`PDFJS_DATA`/`sha256Hex`, imports `apps/web/src/metronomeFont.ts` by relative path, copies `verovio.d.ts` and the engraving options (group 21 #11), and repeats `PdfView`'s hooks (group 03 #12).

## Patterns

- **A small helper written again in each script** (wrangler ×3, argument parsing ×11, "is main" ×3, poll loops ×4, stage-card locator ×7, turns ×3, `pipeline()` ×2, `ROOT` ×2, migrations loop ×4, dotenv ×2, file servers ×2): 11 kinds. Cause: scripts written one at a time, each from a blank file for its occasion, with no typecheck or tests to make a shared module pay off; the shared modules that exist (config.ts, appServers.ts) grew later and the older scripts weren't moved onto them.
- **Constants restated across files and processes** (`FIXTURES`, the test PDF, `BUCKET`, `DATABASE`, the config file name, localStorage keys, `Host`, `WindowTheme`): 8.
