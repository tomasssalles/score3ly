# 06 web: running the pipeline

Cross-batch patterns seen across these files (each also noted per file):
- **"The latest stage of step X before this one"** is written by hand ~20 times: `pipeline.stages.slice(0, findIndex(id)).reverse().find(...)` or `[...earlier].reverse().find(...)` (steps.ts, runSkewAnalysis, runLayout, runAnalyze, runBuildMei, runEngrave, finishFix*, finishHumanReview, toasts). `Array.prototype.findLast` would do it, but `tsconfig.json` has `lib: ES2022` (findLast is ES2023): a lib bump plus one helper `latestBefore(stages, stageId, steps)`. check.
- **Canonical JSON to bytes, then `putContent(…, "application/json")`**: a local `json` const in runAnalyze, runExtract, runReview, runApplyReview; inline in runLayout, runSkewAnalysis; `linesBytes` (finishFixSkew), `layoutBytes` (finishFixLayout), `jsonBytes` (finishFixMetadata, imported by finishFixObservations, finishHumanReview, ExtractionView). One `putJson(value)` in api.ts would replace all. certain.
- **"Answer can't be used": `markUnusable(...).catch(() => {})` then throw** repeated in runLayout, runAnalyze (×3), runExtract, runReview, runApplyReview (which alone has a local `unusable` helper). certain.
- **Loading a failed run's recorded outputs into a Map** (`stage.outputs.filter(type).map([item,o])` + `Promise.all(fetchJsonContent)`) in runAnalyze, runExtract, runReview, runApplyReview. certain.
- **matchMedia hooks** written three times: useWide.ts, navigation.ts `useNoBrowserBar`, themes.ts `darkQuery`: a generic `useMediaQuery`. certain.
- **Three Web Worker RPC clients** (id counter + pending Map + message/error listeners): pageImages.ts, rendering.ts, meiValidation.ts (batch 07). check.
- **Plural "N thing(s)"** inline in runRasterize, runEngrave, layout.ts `layoutNote`, analyze.ts `analyzeNote`, skewNote: a `plural(n, word)` helper. check.
- **Two `duration` functions**: runTimes.ts `duration(ms)` and time.ts `duration(seconds)` (batch 09), used side by side (RunTimesTab/EffortTab vs StageCard/StageDetails). certain.
