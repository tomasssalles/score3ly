# 08 web: project screens

## apps/web/src/ProjectView.tsx
**What it does:** the project screen and the pipeline's driver in the browser. Loads the pipeline, polls it while a stage runs on another device (every 5 s) and refetches when a remote heartbeat goes stale; runs the current stage through `RUNNERS` with an `AbortController`, and in Auto mode chains to the next (recursive `run`); finishes manual stages (`FINISHERS`), resolves carried manual stages (one shared in-flight promise), adds fixes / reviews / human reviews, edits, drops, changes configs (opens `ConfigDialog`, loads page count and model configs), downloads, sets the run mode (optimistic, rolled back on failure). Asks for confirmation when a change replaces stages that ran (`replacesWork`/`replacesLater`/`fixReplaces`). Toasts in narrow mode: diffs pipeline snapshots, gathers events for 500 ms, shows 4 s, suppressed 3 s after the user's own action. `beforeunload` prompt, wake lock and in-app leave guard while running. Wide/narrow layouts, collapsible side panel (remembered in localStorage) with a collapsed "strip" progress.
**Exports:** `ProjectView`.
**Imports:** api (many), finishers, ArtifactView, ConfirmDialog, icons, pipeline, PipelinePanel, ProgressRing, ConfigDialog, runners, stageRunner (`CannotStart`), wakeLock, leaveGuard, steps, humanReview, pageImages, downloads, StageDetails, toasts, useWide. React. Platform: `localStorage`, `beforeunload`.
**Notable internal helpers:** `readFlag`/`writeFlag` (boolean in localStorage with try/catch); `modelConfigsFor` (model configs + the stage's own deleted one); `StripProgress`; the toast gathering (a debounce with a quiet window).
**Findings:**

- L698–713 `readFlag`/`writeFlag`: a remembered localStorage flag with try/catch; the same pattern as `useRemembered` (ExtractionView.tsx L195) and the localStorage code of themes.ts and cacheLru.ts. Probably one shared helper. check
