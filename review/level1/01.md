- **Exports:** `STRETCH_CLASSES`, `MEASURE_KINDS`, `BAR_LINES`, `GROUP_SYMBOLS`, `ISSUE_CLASSES`, types `Box`, `LensStaff`, `LensGroup`, `LensVoice`, `LensChange`, `LensEnding`, `LensStretch`, `LensAnswer`, `LensIssue`, `LensSystem`, `StretchPlace`, `CodeIssue`, `Warning`, `ScoreState`, `SystemContext`, `CheckedSystem`; `pieceStart`, `checkSystem`, `tempoProblem`.
- **Imports:** fraction.ts, durations.ts, spans.ts, symbolic.ts.
- **Notable internal helpers:** `Unusable` + `fail` (throw-to-return), `stretchAnswers`, `tempoText` (re-serializes a tempo), `measureWarning`.
- **Findings:**
  - 451–453: the comment "A measure's length against its kind and time…" sits above `tempoProblem`; it belongs to `measureWarning` (482). Certain.
  - 120–121: only the top level is checked before the answer is trusted; a stretch without `changes`/`voices` or an issue without `boxes`/`answers` throws a TypeError that `checkSystem` rethrows instead of returning a problem. Check (constrained output makes it unlikely).
  - 18, 243–246: `Box` and its validation duplicate imaging's. Certain.
  - 207: the multi-measure-rest test ignores clef/ottava/stem events but not `tempo`, `changeStaff` or `event`, so `\tempo … R1*4` isn't seen as a multi-measure rest. Check.
  - 119–441: `check` is one 320-line function. Check (could split structural checks from the questions and the measures).
  - 475–480: `tempoText` re-serializes a tempo just to compare; comparing the parsed `Tempo` objects would do. Certain (minor).
- **Tests:** broad (per area of the checks, state carried, curves across systems, ottava/pedal, endings, issues, staff order, clefs carried, tempo). The `stretch`/`system`/`checked` builders are copied between lens.test.ts, links.test.ts, scoreChecks.test.ts and mei.test.ts. Certain.

## packages/notation/src/score.ts
- **What it does:** builds the whole score from the systems' answers: pieces from the piece starts, every voice string parsed into runs, each stretch's length, the piece's staves (order merged across systems, labels and abbreviations), voices, measures from the stretch classes with numbering from 0 or 1 by whichever matches the printed numbers; offsets of stretches in a measure, a measure's length, `@tstamp` from an onset.
- **Exports:** types `ScoreSystemInput`, `Run`, `ScoreStretch`, `MeasurePart`, `ScoreMeasure`, `PieceStaff`, `ScorePiece`, `Score`; `buildScore`, `stretchOffsets`, `measureLengthOf`, `tstamp`.
- **Imports:** fraction.ts, durations.ts, types from lens.ts, symbolic.ts.
- **Findings:**
  - 62, 126: every voice string is parsed again (already parsed in `checkSystem`), and `restCount` parses the stretch's strings a third time though the runs exist. Certain (perf, minor).
  - 82–84: lookups return `!`-asserted values; an unknown system or stretch gives `undefined` typed as defined. Check.
  - 195: `measureLengthOf` is used nowhere (grep: only defined). Certain (dead code).
- **Tests:** none of its own; through mei.test.ts (numbering, pickups, split measures).

## packages/notation/src/spans.ts
- **What it does:** follows marks with two ends through one system's voices (curves, hairpins, trill spans, glissandos per voice; ottavas, pedal per staff, following `\change Staff`), opening and closing them, recording problems (as message plus page question) and marks closed from earlier systems; checks that carried short marks end on this system.
- **Exports:** types `OpenMark`, `ClosedMark`, `SpanProblem`; `describeMark`, `markName`, `SpanTracker`, `sameMark`.
- **Imports:** `walk`, types from symbolic.ts.
- **Findings:**
  - 307: dynamics written out instead of `DYNAMICS`. Certain.
  - 256–257: `whereEnds` is private; scoreChecks.ts 47 writes the same question by hand. Certain.
  - 276, 335: the `staff` parameter is reassigned. Certain (cosmetic).
  - `unaCorda`/`treCorde` aren't tracked as spans, while `sustainOn/Off` are. Check (intended?).
- **Tests:** through lens.test.ts (curves across systems, ottavas and pedal).

## packages/notation/src/links.ts (+ links.test.ts)
- **What it does:** the repeat structure of a piece (where each end repeat goes back to, endings with their neighbours, warnings for unbalanced repeats and lone endings) and, per system, sentences describing its links (repeats, endings, marks crossing system breaks) for `review`'s requests.
- **Exports:** types `GoBack`, `EndingSpan`, `LinkedSystem`; `repeatStructure`, `endingPlaces`, `systemLinks`.
- **Imports:** type `CheckedScoreSystem` from scoreChecks.ts (which imports this file: a cycle, type-only); spans.ts; types from lens.ts.
- **Findings:**
  - 80 and 120: the ending's name ("The ending "…"" / "An ending") is written twice. Certain.
  - 107–111: piece splitting duplicated (batch-wide). Certain.
  - 131: dedup key `${m.kind}/${JSON.stringify(m)}` repeats `kind` and depends on property order. Certain (minor).
  - 45, 64: a start repeat printed both as the right bar line of a system's last stretch and as the next system's `startRepeat` would call `start` twice and warn "Two start repeats". Check (depends on how the prompt asks to report it).
  - 92: `firstMeasureStretch` = mei.ts `firstStretch`. Certain.
- **Tests:** go-backs, endings linked, marks across breaks, pieces apart. Builders copied from the other tests (see lens.ts).

## packages/notation/src/mei.ts (+ mei.test.ts)
- **What it does:** builds MEI 5 from the score and metadata: the header (fileDesc, encodingDesc, workList with components, manifestationList), the facsimile (a zone per MEI measure part), and per piece a single pass (`PieceWriter`) resolving written and sounding pitches (key, measure accidentals per voice/octave/ottava epoch, ties), ottavas by time per staff, curves as ties or slurs, hairpins, trills, glissandos, pedals, dynamics (between braced staves), texts as dynam or dir by their words, tempo with SMuFL metronome glyphs, tuplets, graces, fTrem/bTrem, beams, cross-staff notes, multi-measure rests, endings, scoreDef changes, system/page breaks, measures divided at inner bar lines (or at system breaks for a system alone or engrave's copy), dropping references that point outside a system alone; also strips BEYOND_BASIC for validation. Generic: a greedy "length as note values" decomposition, a timed walk over nested events.
- **Exports:** `MEI_VERSION`, `MEI_NS`, `BEYOND_BASIC`, types `MeiMetadata`, `MeiApplication`, `MeiOptions`, `Segment`; `buildMei`, `meiString`, `withoutBeyondBasic`, `zoneId`, `measureSegments`, `clefAttrs`, `keyAlteration`, `isDynamicText`, `tempoContent`.
- **Imports:** fraction.ts, durations.ts, types from lens.ts, score.ts, symbolic.ts, xml.ts.
- **Notable internal helpers:** `spaceValues`, `valueOf` (both loop `[0.5, 1, …, 128]`, = `NOTE_VALUES`), `sub`, `setRef`, `refsOf`, `walkTimed`, `segmentParts`, `partBox`.
- **Findings:**
  - 904: dynamics list by hand again (see spans.ts). Certain.
  - 325, 1026: subtraction inline and as a private `sub`; belongs in fraction.ts. Certain.
  - 321, 333: the note-value list written twice. Certain.
  - 683, 984, 1036: three hand-written attribute remaps; xml.ts `setAttr` unused. Certain.
  - 1022: `firstStretch` = links.ts `firstMeasureStretch`. Certain.
  - 416–417: `elements(el("section", {}, sectionChildren))` built twice; 1003: `segmentParts(segment)` computed twice. Certain (minor).
  - 102–104, 120–123: the composer/lyricist/arranger lines written twice (titleStmt and work). Certain (minor).
  - 239: an unknown clef silently becomes treble. Check (clefs are normalized by the parser, so only an inconsistent lens could hit it).
  - 1044–1054: `walkTimed` repeats the onset arithmetic of `events()` (631–652); lens.ts `tempoProblem` 454 has a third, flat version. Check.
  - 88: `header_` named with a trailing underscore to avoid the local `header`. Certain (naming).
  - 773–774: `{ ...notes[0], duration: half, tremolo: null } as Event` casts. Certain (minor).
  - 1055 lines: header, facsimile and music in one file. Check (split header and facsimile out).
- **Tests:** a rich score validated against MEI 5 and MEI Basic (xmllint-wasm, RelaxNG), systems alone, no metadata, BEYOND_BASIC removal, pitches, ottava, ties/slurs, split measures, numbering, dynamics between staves, escaping, inner bar lines, engrave's divided copy, tremolos, tempo. Nits: 87 and 88 repeat the comment "A second piece."; 73 sets `s2.stretches[2].rightBarLine = "startRepeat"`, already set in the stretch's own options above; 82 `"\"treble_8\"".replace(...)` is just `"treble_8"`; `attrOf` (136) duplicates xml.ts `attr`. Certain.
