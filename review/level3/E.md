### P2: bugs that will hurt
- **E4. Which stage owns a call: one rule for cache, export, import, replay, deletion** [C12; 08 #4, #13; 15 #4, #5; new: deletion of consumed-but-unnamed calls]. Today: cache hit writes no row; export = own rows + calls outputs name (`servedTo`, first of an unordered result); import revives/matches in place (the imported stage owns none of them); replay reads own rows only (a stage without own calls drops out of `recordedStages` and shifts turns); deletion keeps a call alive only through its stage or a live output. Real projects' fixtures will fail the replay at `layout` round 1, a "delete, re-import the backup" leaves the imported project's unnamed calls on a deleted stage (re-marked and collected at the next deletion), and the export of an imported project is not whole.
  **Rule proposed (settles C12):** *every stage has a row for every call it consumed; exactly one row per paid call carries the cost.* A cache hit inserts a row for the serving stage (`served_from` = the original call's id, status `ok`, cost 0, same request/response hashes, the stage's item and round). Then: export = the stages' own rows (`servedTo` goes; a served row whose original isn't exported is exported as the original's content with `served_from` cut); import = every call row of a copied stage becomes a row of the imported stage (matched live call → served row naming it; deleted match → the original revived in place for its cost *and* a served row for the imported stage; else a new row); replay unchanged (own rows); deletion unchanged in SQL and now correct (a consumed call's row lives with the consuming stage; `collectOrphans` keeps objects any live row names). The cache lookup skips served rows (`served_from IS NULL`) or not (same answer) — pick one. Statistics (Usage, run times, call counts) must skip or label served rows: C24's `callRecords.ts` defines the predicate, F's tabs use it. Tests: export/import/replay of a project with a layout served from another project's calls; delete A, B keeps its rounds. check (design: owner), certain (mechanism). **Stored:** `llm_calls.served_from` (migration), new rows on hits, `EXPORT_FORMAT` 2; the fake fixture re-made with `npm run fixture:fake` (free).
