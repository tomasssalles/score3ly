## Decisions for the project owner

1. **Same answer** for a repeated or written answer: case-insensitive everywhere (proposed) or case counts (humanReview today) [D24; 18 #4].
2. **Code-issue identity:** stable `kind` + places stored on the issue, or keep text + boxes [D12].
3. **prompts imports notation's lens types and enums** (root or `./lens`), ending the copies and the cross-package enum test [D22].
4. **Two-systems rule for extract:** enforce (as docs say) or document the exception [D8].
5. **Pieces in the page call:** tell the model "only pieces starting on this page", or drop others silently instead of refusing [D18b]; and what a piece's `page` means [D20].
6. **`startEndRepeat` → `bothRepeats`** in analyze (paid) or translate in `systemHints` (free) [D18c].
7. **Should the review see that a choice was a revert** [D18d].
8. **A done `engrave` whose stored recipe today's code can't make:** show it remade with a warning, or mark it stale [D13].
9. **Guard on prompt versions:** a test pinning text+schema hashes to versions [D15].
10. **Answer-key rule:** "a, b, c in order" for every creator, or first unused letter [D7].
